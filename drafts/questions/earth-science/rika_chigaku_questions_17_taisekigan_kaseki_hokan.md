# 理科問題案：堆積岩と化石の補完

対象は中学理科の地学分野「大地の成り立ち」。既出のれき岩・砂岩・泥岩・凝灰岩に加え、石灰岩・チャートと、化石から地層ができた環境を読み取る基本事項を扱う。
答えが特定の名称に定まる10問とする。

| No. | 問題文 | 正解 | 別解 | 分類 |
|---:|---|---|---|---|
| 1 | サンゴや貝などの死がいが積もってできた、主に炭酸カルシウムからなる堆積岩を何というか。 | 石灰岩 |  | 堆積岩 |
| 2 | 放散虫などの小さな生物の殻が積もってできた、硬くて緻密な堆積岩を何というか。 | チャート |  | 堆積岩 |
| 3 | 植物の遺骸が長い時間をかけて変化してできた、黒色の可燃性の物質を何というか。 | 石炭 |  | 堆積物 |
| 4 | 石灰岩の主な成分は何か。 | 炭酸カルシウム |  | 堆積岩 |
| 5 | 石灰岩にうすい塩酸を加えたときに発生する気体は何か。 | 二酸化炭素 |  | 堆積岩 |
| 6 | 生物の足跡・はい跡・巣穴など、からだそのものではない生活のあとが残った化石を何というか。 | 生痕化石 |  | 化石 |
| 7 | 暖かく浅い海にすんだことを示す代表的な示相化石は何か。 | サンゴ | 珊瑚 | 示相化石 |
| 8 | 淡水や河口付近の環境を示す代表的な示相化石は何か。 | シジミ | 蜆 | 示相化石 |
| 9 | 寒冷な気候の陸上環境を示す代表的な示相化石は何か。 | ブナ |  | 示相化石 |
| 10 | 地層の中から見つかる、当時の生物のからだの一部が残った化石を何というか。 | 体化石 |  | 化石 |
