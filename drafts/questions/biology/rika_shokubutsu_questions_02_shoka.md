# 理科問題案：消化と吸収

対象は中学理科の「動物のからだのつくりと働き」のうち、消化と吸収に関する範囲。
消化器官、消化液・消化酵素、柔毛での吸収までを扱う。答えはできるだけ教科書用語に限定する。
