# 理科問題案：窒素循環と環境保全の補充

生態系の物質循環のうち窒素の循環と、自然環境を守るための考え方を扱う補充範囲。高校入試で出題されることがある発展的な内容も含む。

| No. | 問題文 | 正解 | 別解 | 分類 |
|---:|---|---|---|---|
| 1 | タンパク質や遺伝子をつくる物質に含まれる元素を何というか。 | 窒素 |  | 窒素循環 |
| 2 | 空気中に最も多く含まれ、植物がそのままでは利用しにくい気体を何というか。 | 窒素 |  | 窒素循環 |
| 3 | 空気中の窒素を、植物が利用できる化合物に変える働きを何というか。 | 窒素固定 |  | 窒素循環 |
| 4 | マメ科植物の根に共生し、窒素固定を行う細菌を何というか。 | 根粒菌 |  | 窒素循環 |
| 5 | 生物の遺体や排出物が分解されるときに生じる窒素化合物を何というか。 | アンモニア |  | 窒素循環 |
| 6 | アンモニアを亜硝酸や硝酸に変える細菌を何というか。 | 硝化菌 |  | 窒素循環 |
| 7 | 硝酸などの窒素化合物を窒素に戻し、空気中へ放出する働きを何というか。 | 脱窒 |  | 窒素循環 |
| 8 | 生産者・消費者・分解者の働きによって、窒素が生態系の中を移動することを何というか。 | 窒素循環 |  | 窒素循環 |
| 9 | 環境を守りながら資源を利用し、将来の世代も利用できるようにする考え方を何というか。 | 持続可能性 |  | 環境保全 |
| 10 | 開発を行う前に、環境への影響を調査・予測・評価することを何というか。 | 環境アセスメント |  | 環境保全 |
