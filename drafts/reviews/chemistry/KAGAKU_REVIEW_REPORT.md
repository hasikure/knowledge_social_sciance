# 化学クイズ（kagaku-01〜09）修正依頼

対象: `drafts/csv/chemistry/kagaku_questions_draft.csv`（140問）
作成: 2026-08-03
観点: ①事実の正しさ ②中学（公立高校入試）の範囲 ③答えの一意性・表記ゆれ

判定仕様は `assets/quiz.js` の `normalizeAnswer()` を前提にしている。
**カタカナ⇄ひらがな・全角英数⇄半角・空白・長音/中黒・カッコ・大文字小文字は自動で吸収される**ので、
これらのための別解は書かない。効かないのは**漢字の読み**と**全角コロン**と**下付き文字**。

内訳: 削除推奨 12問 / 問題文・答えの修正 10問 / `accept` 修正 15問 / kagaku-09 の増補 3〜4問

**不足している問題（追加すべき項目）は `KAGAKU_MISSING_QUESTIONS.md` に分けて書いた。**

## A. 仕様違反 — 直さないと別解が1つも機能しない（最優先）

## B. 事実・用語として誤っている

### B-1. kagaku-04 q-02（57行）— 定義が逆

- 現状: label `同じ種類の原子を何というか。` / answer `元素`
- 問題: 元素は「原子の**種類**」であって「同じ種類の原子」ではない。定義が逆になっている。
- 修正: label を `原子の種類のことを何というか。` に変更。

### B-2. kagaku-02 q-17（37行）— answer と accept が逆

- 現状: answer `線香` / accept `火のついた線香`
- 問題: 「線香」だけでは気体の確認方法として成立しない。正解側が不十分な表記になっている。
- 修正: answer `火のついた線香` / accept `線香`

### B-3. kagaku-06 q-04（92行）— 生成物名も正解にすべき

- 現状: label `鉄が空気中の酸素や水とゆっくり酸化してできる赤褐色の物質を何というか。` / answer `さび` / accept `錆`
- 問題: 生成物を問う形なので「酸化鉄」も事実として正しい。
- 修正: accept を `錆|酸化鉄` に。

### B-4. kagaku-08 q-14（132行）— 高校の表記

- 現状: answer `鉄(II)イオン`
- 問題: ローマ数字による酸化数表記は高校範囲。中学では「鉄イオン」。
  加えて answer に括弧があるため、`withoutParen()` で `鉄` `II` にも分解されてしまう。
- 修正: answer `鉄イオン` / accept `Fe2+`（A項の区切り修正を兼ねる）
