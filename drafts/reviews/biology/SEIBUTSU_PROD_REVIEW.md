# 生物クイズ（rika-* 13クイズ）修正依頼

対象: `data/items_rika-*.csv`（本番デプロイ済み・240問）
作成: 2026-08-05
観点: ①事実の正しさ ②中学（公立高校入試）の範囲 ③答えの一意性・表記ゆれ

## 対象を本番データにした理由

`drafts/csv/biology/seibutsu_questions_draft.csv`（268問）は**すでに本番へ反映済みで、その過程で大幅に整理されている**。
ドラフトを直しても本番には効かないので、本番の `data/items_rika-*.csv` を対象にした。

同じ `drafts/reviews/biology/` にある `SEIBUTSU_REVIEW_REPORT.md` は**このドラフトに対する古いレポートで、指摘はすべて対応済み**。
歴史的資料として残してあるが、現状の点検には使えない（末尾で `assets/quiz.js` に提案している
かな⇄カナ・全角半角の自動正規化は、すでに `normalizeAnswer()` に実装されている）。

ドラフト側で見つかる不具合も**すべて本番では解消済み**だった。参考までに:

| ドラフトの問題 | 本番での状態 |
|---|---|
| seibutsu-09 q-12/q-13 の accept が `F₁、第一世代、子の代` と読点区切り | `F₁\|第一世代\|子の代\|子\|子世代` に修正済み |
| seibutsu-06 に「葉緑体」3問・「細胞液」2問・「核」2問などの重複（20問） | 重複を削って13問に整理済み |
| seibutsu-01 に「道管」3問 | 2問に整理済み |
| seibutsu-02 q-15 の accept が `柔毛（じゅうもう）`（カッコ除去で `柔毛じゅうもう` になり一度も一致しない） | `じゅうもう\|絨毛` に修正済み |
| seibutsu-09 q-14「分離」（用語として不正確） | 削除済み |
| seibutsu-01 q-20「昼と夜のどちらに呼吸を行うか」→「昼も夜も」（二択に見えて答えが両方） | 「昼だけか、夜だけか、昼も夜もか」に修正済み |
| seibutsu-02 q-19「脂肪酸とグリセリン」 | 「脂肪酸とモノグリセリド」に修正済み |

**ドラフトは役目を終えているので削除してよい。** 残す場合は本番と食い違っている旨を明記しないと、
次に読んだ人が差分を「未反映の修正」と誤解して戻してしまう。

以下は**本番データに残っている**指摘。

## A. 事実・出題として問題がある

### A-1. rika-shigeki-hannou q-05 — 問題文に答えが書かれている

- 現状: label `目に入る光を屈折させ、網膜に像を結ばせる` **`レンズのような部分`** `を何というか。`
  / answer `水晶体` / accept `レンズ`
- 問題: `レンズ` を別解にしているため、**問題文の語をそのまま打てば正解になる**。
  水晶体を知らない生徒が通ってしまい、習熟度が実態とずれる。
  HANDOFF.md で4択をやめた理由（「地形の分類を答えさせる問題は名前に答えが入っている」）と同じ構造。
- 修正: accept から `レンズ` を外す。あわせて label を
  `目に入る光を屈折させ、網膜に像を結ばせる部分を何というか。` にする。

### A-2. rika-kankyou q-02 / q-03 — 高校生物の用語

- 現状: q-02 `個体群`（ある地域の同種の生物の集まり）/ q-03 `生物群集`（さまざまな種類の生物の集まり）
- 問題: どちらも**高校生物の用語**で、中学教科書には出ない。公立高校入試でも問われない。
- 修正: 2問とも**削除**。
  あわせて q-04 が「ある地域の**生物群集**と、それを取り巻く環境を…」と q-03 に依存しており、
  内容も `rika-seitaikei` q-01 とほぼ同じなので **q-04 も削除**でよい。
  削除しても22問→19問で、1ラウンド10問は確保できる。

### A-3. rika-kankyou q-09 / q-11 — 教科書用語ではなく答えが割れる

| item | 現状 | 問題 |
|---|---|---|
| q-09 | `生息地破壊` | 中学教科書に定着した語ではない。「生息地の破壊」「開発」「森林伐採」などに割れて正答に届かない |
| q-11 | `自然保護区` | 同上。「保護区」「国立公園」「自然保護地域」などに割れる |

- 修正: **2問とも削除**を推奨。環境分野は用語より現象（酸性雨・温暖化・外来種）で問うほうが入試に近い。
  補充は `SEIBUTSU_MISSING_QUESTIONS.md` の M-12 を参照。

### A-4. rika-seitaikei q-13 — 答えが一意でない

- 現状: `食物連鎖を通って、生物から生物へ受け渡されるものは何か。` / answer `エネルギー`
- 問題: 「有機物」「養分」「炭素」も事実として正しく、どれも落とせない。
- 修正: accept に `有機物|養分` を追加する（手軽）。
  厳密にしたいなら label を `食物連鎖で、生物が生きるために利用している、食物にふくまれるものは何か。` などに変える。

### A-5. rika-shigeki-hannou q-20 — 中学では用語として問わない

- 現状: answer `瞳孔反射`
- 問題: 中学ではこれを**「反射」の一例として扱うだけ**で、名称は問われない。
  正しく理解している生徒が「反射」と答えて不正解になる。
- 修正: accept に `反射` を追加する。
  または label を `明るいところで瞳孔が小さくなるように、意識とは関係なく起こる反応を何というか。` として
  answer を `反射` に変更する。

## D. 構成上の指摘

### D-1. rika-shinka に地学が7問混ざっている

`q-03`（地層の新旧）`q-04`〜`q-07`（示準化石・示相化石）`q-14`（地質時代）`q-15`（三葉虫）`q-16`（アンモナイト）は
**中1地学「大地の変化」の内容**。全16問のうち7問を占める。

進化の証拠として化石を扱う流れ自体は自然なので誤りではない。ただ `drafts/` に
`rika_chigaku_questions_11_chishitsu_jidai.md` や `..._17_taisekigan_kaseki_hokan.md` があり、
**地学クイズを作ると示準化石・示相化石・地質時代が二重になる**。先に置き場所を決めておくとよい。

地学へ移す場合、rika-shinka は9問になるため `SEIBUTSU_MISSING_QUESTIONS.md` M-10 の補充が前提になる。

**顕微鏡の問題が1問も無い**のが主因（`SEIBUTSU_MISSING_QUESTIONS.md` M-6 参照）。

### D-3. category の粒度

`rika-kankyou` は q-01〜q-04 が `生態系`、q-05 以降が `生物多様性` / `環境問題` / `地球環境` / `環境保全`。
A-2 で q-02〜q-04 を削ると `生態系` カテゴリが q-01 の1問だけ残るので、`生物多様性` に寄せて統一するとよい。
