# 理科一問一答クイズ問題データ（ドラフト）精査レポート

`chishiki-quiz/drafts/csv/biology/seibutsu_questions_draft.csv` に登録されている理科の一問一答形式クイズ用CSVデータ（全269問）について、以下の4つの観点から精査を行いました。

1. **問題文の表現の適切さ**
2. **完全一致判定における表記ゆれ対策の有無**（`accept` 列の設定状況）
3. **事実関係の正確さ**
4. **中学校・公立高校入試の範囲としての適切さ**

---

## 1. 総評

全体として中学理科の生物分野（中2・中3）の重要語句が非常によく網羅されています。社会の時のフィードバックを反映して `accept`（別解）列が導入されている点は大変素晴らしいですが、**「ひらがな・カタカナ」の表記ゆれ、別名（略称）の登録漏れがまだ多く、このままリリースすると完全一致判定により不正解となってしまうケースが多数見受けられます**。

また、**高校生物で扱う「窒素循環」関連の専門用語が複数含まれており、これらは公立高校入試の範囲を逸脱しているため、削除または調整が必要**です。その他、同一問題の重複（バグ）も数件発見されました。

以下に、具体的な指摘事項と修正案をまとめました。

## 3. 今後のメンテナンスにおけるアドバイス

社会クイズの精査レポートでも提案しましたが、今回のドラフトでも `accept` 列に入力された別解が「完全一致」で判定されるため、全角・半角の違いや、カタカナ・ひらがなの違いをすべて手動で登録するのは非常に困難です。

やはり、正誤判定ロジック側（`assets/quiz.js`）で、以下の自動補正を行うように改修することを強くお勧めします。

1. **ひらがな・カタカナの自動正規化**: 入力されたカタカナをひらがなに（またはその逆に）内部で自動変換して判定する。
2. **アルファベットの大文字・小文字の自動正規化** (`dna` / `DNA` / `Ｆ１` / `F1` など)。
3. **全角・半角のコロンや数字の自動正規化**。
